# Security

Rivo FX sits on the trust boundary between players and servers, so security reports matter a lot to us.

**Please don't report vulnerabilities in public issues.** Use GitHub's [private vulnerability reporting](https://github.com/RivoLabs/rivo_fx/security/advisories/new) instead. Include:

- what an attacker can do, and from where (a client, another resource, the network)
- the smallest resource or payload that shows it
- the Rivo FX version

We aim to reply within a few days, and to ship a fix and an advisory as soon as one is ready. We'll credit you unless you'd rather not be named.

Supported versions: the latest 1.x release.
